# Sécurité

RemoteFileManager manipule des connexions SSH et des fichiers distants. Une vulnérabilité peut donc avoir des conséquences importantes.

Lorsqu’un dépôt public sera créé, les vulnérabilités devront être signalées par un avis de sécurité privé GitHub et non dans une issue publique. Aucun canal de signalement n’est encore ouvert pour ce Sprint 0.

Les règles de conception obligatoires sont décrites dans [docs/security-model.md](docs/security-model.md).
